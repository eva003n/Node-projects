# GitHub User Activity

[Project URL](https://roadmap.sh/projects/github-user-activity)

A lightweight command-line task manager built with Node.js (no external
libraries).

Manage your tasks directly from the terminal --- add, update, delete,
list, and track progress.

------------------------------------------------------------------------

## ✨ Features

-   Fetch activity


------------------------------------------------------------------------

## ⚙️ Installation

Clone the project:

``` bash
git clone https://github.com/eva003n/Github-User-Activity.git
```

Link the CLI globally (so you can run `github-activity` anywhere):

``` bash
pnpm link
```


> If PNPM complains about a bin folder, run:
>
> ``` bash
> pnpm setup
> ```

Confirm setup was successfull, will output absolute path to directory

```bash
pnpm bin -g
```
------------------------------------------------------------------------

## 🚀 Usage

### Fetch activity
Fetch github user activity
```bash
$ github-activity <username>
```
